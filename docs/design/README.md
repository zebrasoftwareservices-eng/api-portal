# Design

Owned by the `ui-designer` subagent.

- `tokens.md` — design tokens as CSS variables (colour, type, spacing, radius). Customer
  themes override these; components never hard-code values.
- `NNN-<slug>.md` — one file per spec: user flow, screens (ASCII wireframes), states,
  components, copy, accessibility, responsive behaviour.
- `jso-316-unified-api-portal.md` — implementation-ready north-star information architecture,
  journeys and wireframes for the developer and administrator portals.
