
**Design (tech-lead, 2026-11-15).** Search is computed at query time from `publishedApis(db, viewer)`, the same function behind the catalog, so visibility, publish state and latest version can't drift and there's no index, migration or new container (ADR 0012). Added `GET /v1/search` (`q` 1–100 chars, `limit` ≤ 50, 60/min anonymous per IP and 120/min per user) to `openapi.yaml`, with a pure `searchCatalog` matcher in `@portal/sdk` shared by the server and demo mode. Ten tasks are split across backend, frontend and QA; the main risks are operation deep-link anchors in Scalar and per-search cost on large catalogs, each with a named test.
