
Design (tech-lead, 2026-11-15): The server renders /llms.txt, a Markdown reference and a raw spec download per API and version on request from the stored documents, behind the catalog's visibility check; the portal serves /llms.txt at its root by forwarding to the server without cookies, so it is always the anonymous view (ADR 0013). Code samples come from Scalar's built-in clients (curl, JavaScript, Node.js, Python, Go, Java), and there is no migration, adapter call or new dependency. Five catalog routes and the markdownUrl/downloadUrl fields are in openapi.yaml; 12 tasks are split across backend, frontend and QA, and the status is now designed.
