## Product manager — 2026-11-22
Wrote spec 027 (Trace inside Try it) at status draft: a signed-in developer or admin sees the Kong trace waterfall for their own Try it call under the response, per Elango's 2026-11-22 decision reversing 026 Decision 2 for Try it only.
