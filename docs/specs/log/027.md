## Product manager — 2026-11-22
Wrote spec 027 (Trace inside Try it) at status draft: a signed-in developer or admin sees the Kong trace waterfall for their own Try it call under the response, per Elango's 2026-11-22 decision reversing 026 Decision 2 for Try it only. Nine criteria cover the per-call trace tied by a W3C `traceparent`, isolation between users, the developer-versus-admin span view, one Try it trace per user, and the off, not-arrived and gateway-down paths. Proposed defaults (trace only when tracing is on; plugin names for admins only; 30 s wait) are marked in the criteria and listed as open questions for Elango and the tech lead.
