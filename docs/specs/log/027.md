## Tech lead — 2026-11-22

The Try it proxy issues a random W3C `traceparent` for signed-in callers whose call is covered by an active selection, the portal's Kong tracing plugins now extract W3C context, and a new `try_it_traces` table keeps one trace per user that ingest fills by trace id; `GET /v1/try-it/traces/{traceId}` answers only the owner (others 404, anonymous 401) and hides plugin names from non-admins.
