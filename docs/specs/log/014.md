## Tech lead · 2026-11-23, design
Pages are Markdown rows in Postgres and the portal renders them with raw HTML dropped; the header
and footer are one saved document that the server resolves per caller (ADR 0020). One SQL condition
decides who reads a page, and the public page, navigation and search all use it, so a draft or a
signed-in-only page never reaches a caller who may not see it. The contract is in `openapi.yaml`
with 12 tasks for backend and frontend and 2 for QA; there are no gateway calls and no new services.
For the ui-designer: the default navigation must leave the admin topbar as it is (criterion 1),
whichever way the open question goes.
